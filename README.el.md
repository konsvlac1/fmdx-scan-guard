# Scan Guard για το FM-DX Webserver

🇬🇧 [English](README.md)

**Το Scan Guard προστατεύει τον δημόσιο FM-DX Webserver σας με δύο τρόπους:**

### 1. Κρατά μακριά τα «ρομπότ» τεχνητής νοημοσύνης (AI crawlers) 🚫
Εταιρείες όπως η OpenAI (ChatGPT), η Anthropic (Claude), η Perplexity, η Google (για εκπαίδευση AI),
το Common Crawl, η ByteDance (TikTok) και η Meta στέλνουν ρομπότ («crawlers») που διαβάζουν
ιστοσελίδες για να εκπαιδεύσουν την τεχνητή τους νοημοσύνη. Το Scan Guard κάνει ό,τι και σελίδες
όπως το Piratenscan.fm:
- λέει σε αυτά τα ρομπότ να μην μπαίνουν (με ένα αρχείο που λέγεται `robots.txt`), και
- αν έρθουν παρ' όλα αυτά, τα **απορρίπτει** (σφάλμα 403), για τη σελίδα, τα αρχεία και τον δέκτη.

Οι κανονικοί επισκέπτες, οι εφαρμογές κινητού και οι κανονικές μηχανές αναζήτησης (Google, Bing)
**δεν** επηρεάζονται. Αυτό είναι **ενεργό από την αρχή**· μπορείτε να το απενεργοποιήσετε από το παράθυρο της ασπίδας.

### 2. Κρατά μακριά από τον δέκτη σας τα ρομπότ που «σαρώνουν» τη μπάντα 📻
Κάποιοι τρέχουν προγράμματα που συνδέονται σε δημόσιους δέκτες FM-DX και τους συντονίζουν σε όλη
τη μπάντα FM (87.5, 87.6, 87.7 … 108.0 MHz) για να φτιάξουν λίστες σταθμών. Όσο τρέχει ένα τέτοιο
ρομπότ, κανείς άλλος δεν μπορεί να χρησιμοποιήσει τον δέκτη σας.

Το Scan Guard παρακολουθεί **πώς** αλλάζει συχνότητα κάθε επισκέπτης:
- Ένα **ρομπότ** αλλάζει συχνότητα με απόλυτα ίσα βήματα, με απόλυτα σταθερό ρυθμό, σε μεγάλο
  μέρος της μπάντας. Το Scan Guard το αναγνωρίζει και το μπλοκάρει για μία ώρα.
- Ένας **άνθρωπος** αλλάζει συχνότητα ακανόνιστα: πατά προεπιλογές (presets), γράφει μια συχνότητα,
  κρατά πατημένα τα βελάκια, σταματά για να ακούσει. Το Scan Guard αφήνει τους ανθρώπους ήσυχους.
- **Εσείς (ο διαχειριστής)**, καθώς και προγράμματα που τρέχουν στον δικό σας server ή στο δικό σας
  οικιακό δίκτυο, **δεν** μπλοκάρονται **ποτέ**.

Αυτό το κομμάτι ξεκινά σε **λειτουργία παρακολούθησης (Watch)**: τις πρώτες μέρες απλώς σημειώνει
τι *θα* μπλόκαρε, ώστε να το δείτε να δουλεύει πριν μπλοκάρει οποιονδήποτε.

## Με λίγα λόγια: 5 βήματα

1. **Κατεβάστε και εγκαταστήστε** το Scan Guard με μία εντολή ([Raspberry Pi / Linux](#εγκατάσταση-σε-raspberry-pi-ή-linux) ή [Windows](#εγκατάσταση-σε-windows)).
2. **Ενεργοποιήστε το** στη σελίδα του FM-DX: Setup → Plugins → τσεκάρετε *Scan Guard* → Save.
3. Κάντε **επανεκκίνηση** του FM-DX Webserver.
4. Τα ρομπότ AI μπλοκάρονται αμέσως. Για τα ρομπότ που σαρώνουν τη μπάντα, **περιμένετε λίγες μέρες**
   και δείτε τι κατέγραψε: πατήστε το κουμπί με την **ασπίδα 🛡** ή ανοίξτε **Setup → Scan Guard**.
5. Όταν είστε ικανοποιημένοι, πατήστε **Enforce** στο ίδιο παράθυρο. Τέλος.

Κάθε βήμα εξηγείται παρακάτω. Δεν χρειάζεται να ξέρετε προγραμματισμό.

## Τι χρειάζεστε

- **FM-DX Webserver έκδοση 1.4** (σε Raspberry Pi, υπολογιστή Linux ή Windows).
- Περίπου **10 λεπτά**.
- Να μπορείτε να κάνετε **επανεκκίνηση** του FM-DX Webserver και να συνδεθείτε ως **διαχειριστής** (admin).

Χρειάζεται επίσης να ξέρετε **σε ποιον φάκελο είναι το FM-DX Webserver**. Είναι ο φάκελος που περιέχει
τους φακέλους `server`, `plugins` και `web`. Για παράδειγμα:
- Raspberry Pi / Linux: `/home/pi/fm-dx-webserver` (βάλτε το δικό σας όνομα χρήστη αντί για `pi`)
- Windows: `C:\fm-dx-webserver`, ή όπου το αποσυμπιέσατε

## Εγκατάσταση σε Raspberry Pi ή Linux

**Βήμα 1.** Ανοίξτε ένα **τερματικό** (Terminal). Είναι το παράθυρο όπου γράφετε εντολές.
- Αν το Pi έχει οθόνη: πατήστε **μενού Raspberry → Accessories → Terminal**.
- Αν δουλεύετε από άλλον υπολογιστή: συνδεθείτε στο Pi με SSH (για παράδειγμα με το πρόγραμμα PuTTY στα Windows).

**Βήμα 2.** Αντιγράψτε αυτές τις τρεις γραμμές, επικολλήστε τις στο τερματικό και πατήστε Enter.
Στην τελευταία γραμμή, αλλάξτε το `/home/pi/fm-dx-webserver` με τον δικό σας φάκελο FM-DX:

```
cd ~
wget -O scan-guard.zip https://github.com/konsvlac1/fmdx-scan-guard/archive/refs/heads/main.zip && unzip -o scan-guard.zip
sudo node fmdx-scan-guard-main/install.js /home/pi/fm-dx-webserver
```

Αν σας ζητήσει κωδικό, γράψτε τον κωδικό του Pi και πατήστε Enter (δεν φαίνεται όσο γράφετε, είναι φυσιολογικό).
Θα δείτε γραμμές με ✓ και το μήνυμα «Scan Guard is installed».

**Βήμα 3.** Συνεχίστε στο **[Ενεργοποίηση](#ενεργοποίηση-windows-και-linux)** παρακάτω.

## Εγκατάσταση σε Windows

**Βήμα 1.** Πατήστε αυτόν τον σύνδεσμο για να κατεβάσετε το Scan Guard:
https://github.com/konsvlac1/fmdx-scan-guard/archive/refs/heads/main.zip

**Βήμα 2.** Ανοίξτε τον φάκελο **Λήψεις** (Downloads), κάντε δεξί κλικ στο **fmdx-scan-guard-main.zip**,
επιλέξτε **Εξαγωγή όλων…** και μετά **Εξαγωγή**.

**Βήμα 3.** Πατήστε το **πλήκτρο Windows**, γράψτε **cmd** και πατήστε **Enter**. Ανοίγει ένα μαύρο παράθυρο.

**Βήμα 4.** Γράψτε αυτή τη γραμμή και πατήστε Enter. Αλλάξτε το `C:\fm-dx-webserver` με τον δικό σας
φάκελο FM-DX και κρατήστε τα εισαγωγικά:

```
node "%USERPROFILE%\Downloads\fmdx-scan-guard-main\fmdx-scan-guard-main\install.js" "C:\fm-dx-webserver"
```

> Αν δείτε «cannot find module», ο φάκελος που αποσυμπιέστηκε είναι λίγο αλλού.
> Ανοίξτε τον, βρείτε το **install.js**, κρατήστε πατημένο το **Shift**, κάντε δεξί κλικ πάνω του,
> επιλέξτε **Αντιγραφή ως διαδρομή** και επικολλήστε αυτή τη διαδρομή μετά το `node `.

Θα δείτε γραμμές με ✓ και το μήνυμα «Scan Guard is installed».

## Ενεργοποίηση (Windows και Linux)

1. Ανοίξτε τη σελίδα του FM-DX στον browser και **συνδεθείτε ως διαχειριστής** (admin).
2. Ανοίξτε τη **σελίδα ρυθμίσεων** (Setup). Μπορείτε να γράψετε τη διεύθυνση της σελίδας σας με `/setup`
   στο τέλος, για παράδειγμα `https://your-fmdx-page.example/setup`.
3. Πηγαίνετε στο **Plugins**, τσεκάρετε το **Scan Guard** και πατήστε **Save**.
4. Κάντε **επανεκκίνηση του FM-DX Webserver**:
   - Windows: κλείστε το παράθυρο του FM-DX και ξεκινήστε το FM-DX ξανά.
   - Raspberry Pi / Linux, αν το FM-DX τρέχει ως υπηρεσία: `sudo systemctl restart fm-dx-webserver`
5. Έτοιμο. Στα μηνύματα του FM-DX θα δείτε:
   **`[Scan Guard] active, band scanners: watch, AI crawlers: block`**

## Τις πρώτες μέρες: λειτουργία παρακολούθησης (Watch)

Στη λειτουργία Watch το Scan Guard δεν μπλοκάρει κανέναν. Απλώς σημειώνει τι θα είχε μπλοκάρει.

**Για να δείτε τι κατέγραψε:**
1. Ανοίξτε τη σελίδα του FM-DX και συνδεθείτε ως **διαχειριστής**.
2. Ανοίξτε το **μενού ρυθμίσεων** (το γρανάζι ⚙). Κάτω από το «You are logged in as an administrator»
   υπάρχει μια σειρά από μικρά τετράγωνα κουμπιά:

   ![Τα κουμπιά του διαχειριστή: κλειδαριά, κλειδί, άνθρωπος, ασπίδα, αποσύνδεση](docs/admin-buttons.png)

   Πατήστε την **ασπίδα**. Είναι το 4ο κουμπί, ακριβώς πριν από το **Sign out**.
   Μόνο εσείς (ο διαχειριστής) βλέπετε αυτό το κουμπί· οι ακροατές δεν το βλέπουν ποτέ.

   **Ή** ανοίξτε τη σελίδα ρυθμίσεων (Setup) και πατήστε την καρτέλα **🛡 Scan Guard**,
   ακριβώς κάτω από το **Plugins**. Έχει ακριβώς τα ίδια κουμπιά.
3. Ανοίγει ένα παράθυρο με τα **Recent events** (πρόσφατα συμβάντα), για παράδειγμα
   *«would have been blocked (watch mode): band sweep, 87.50→92.50 MHz»*.
   Αν γράφει «Nothing suspicious so far», δεν έχει έρθει ακόμα κανένα ρομπότ.

(Όλα γράφονται επίσης στο αρχείο `scanguard.log` στον φάκελο του FM-DX.)

## Αρχίστε να μπλοκάρετε: λειτουργία Enforce

Όταν είστε ικανοποιημένοι με όσα είδατε:

1. Πατήστε το κουμπί με την **ασπίδα 🛡** ή ανοίξτε **Setup → Scan Guard**.
2. Πατήστε **🛡 Enforce**. Αυτό ήταν, δεν χρειάζεται επανεκκίνηση.

Από εκεί και πέρα, τα ρομπότ αποσυνδέονται και μπλοκάρονται για μία ώρα.
Το κουμπί της ασπίδας είναι **φωτισμένο** όσο το Scan Guard είναι σε Enforce.
Για να γυρίσετε πίσω, πατήστε **👁 Watch**.

### Το παράθυρο της ασπίδας, κουμπί προς κουμπί

- **Band-scanning robots**: **👁 Watch** (μόνο καταγραφή) ή **🛡 Enforce** (μπλοκάρισμα).
- **AI crawlers**: **🚫 Block** (μπλοκάρισμα των ρομπότ AI, προτείνεται) ή **Allow** (επιτρέπονται).
- **Band-scanning robots: blocked now**: ποιες διευθύνσεις είναι μπλοκαρισμένες τώρα, με κουμπί **Unblock**.
- **Recent events**: τι παρατήρησε το Scan Guard τελευταία.

## Δοκιμάστε το μόνοι σας (προαιρετικό, λίγο τεχνικό)

Μπορείτε να παίξετε εσείς τον ρόλο του ρομπότ για να δείτε το Scan Guard να αντιδρά. Το δοκιμαστικό
ρομπότ συντονίζει τον δέκτη σας από τα 87.5 MHz και πάνω, με βήμα 0.1 MHz, ένα βήμα κάθε 0.6 δευτερόλεπτα,
όπως ένα πραγματικό ρομπότ σάρωσης. Οι ακροατές σας θα ακούσουν τη συχνότητα να αλλάζει για περίπου ένα λεπτό.

1. Χρησιμοποιήστε έναν υπολογιστή σε **άλλη σύνδεση internet** από τον server του FM-DX (άλλο σπίτι,
   ή ένα laptop στο hotspot του κινητού σας). Από το δίκτυο του ίδιου του server θεωρείστε
   «δικό σας δίκτυο» και δεν μπλοκάρεστε ποτέ. Ο υπολογιστής αυτός χρειάζεται Node.js·
   ένας δεύτερος server FM-DX είναι ιδανικός.
2. Κατεβάστε εκεί το Scan Guard (την ίδια λήψη όπως στα βήματα εγκατάστασης).
3. Τρέξτε (αλλάξτε τη διεύθυνση με τη δική σας σελίδα FM-DX):
   - Linux: `WS_PATH=/home/pi/fm-dx-webserver/node_modules/ws node fmdx-scan-guard-main/test/bot.js https://your-fmdx-page.example 70 600`
   - Windows: `set WS_PATH=C:\fm-dx-webserver\node_modules\ws` και μετά
     `node fmdx-scan-guard-main\test\bot.js https://your-fmdx-page.example 70 600`
4. Τι πρέπει να δείτε:
   - **Σε Watch:** το ρομπότ τελειώνει όλα τα βήματά του. Στο παράθυρο της ασπίδας 🛡 θα δείτε
     *«would have been blocked (watch mode)»* μετά από περίπου 50 βήματα.
   - **Σε Enforce:** το ρομπότ σταματά με *«closed by server … Automated scanning is not allowed on this tuner»*
     μετά από περίπου 50 βήματα, και το παράθυρο της ασπίδας δείχνει *«blocked for automated scanning»*.
5. Μετά πατήστε **Unblock** στο παράθυρο της ασπίδας, ώστε ο υπολογιστής αυτός να μπορεί ξανά να χρησιμοποιεί τον δέκτη.

## Ξεμπλοκάρισμα

Ένα μπλοκάρισμα λήγει μόνο του μετά από μία ώρα. Για να το τελειώσετε νωρίτερα, πατήστε την **ασπίδα 🛡**
και πατήστε **Unblock** δίπλα στη διεύθυνση. (Η επανεκκίνηση του FM-DX καθαρίζει επίσης όλα τα μπλοκαρίσματα.)

Για να μη μπλοκάρεται ποτέ μια συγκεκριμένη διεύθυνση, γράψτε την στο `whitelist` στο αρχείο
`plugins_configs/scanguard.json`, για παράδειγμα: `"whitelist": ["203.0.113.7"]`.

## Αφαίρεση του Scan Guard

Τρέξτε ξανά τον εγκαταστάτη με `--uninstall` στο τέλος και κάντε επανεκκίνηση του FM-DX Webserver.
- Linux: `sudo node fmdx-scan-guard-main/install.js /home/pi/fm-dx-webserver --uninstall`
- Windows: η ίδια γραμμή όπως στην εγκατάσταση, με ` --uninstall` στο τέλος.

Όλα επιστρέφουν ακριβώς όπως ήταν.

## Μετά από ενημέρωση του FM-DX Webserver

Μια ενημέρωση του FM-DX μπορεί να αναιρέσει τις γραμμές του Scan Guard στο `server/index.js`.
Απλώς τρέξτε ξανά το βήμα εγκατάστασης (την ίδια γραμμή όπως πριν). Μπορείτε να το τρέξετε όσες φορές θέλετε.

## Ερωτήσεις

**Το παράθυρο της ασπίδας ή η καρτέλα στο Setup γράφει «One more step is needed»;**
Το Scan Guard αντιγράφηκε με το χέρι στον φάκελο `plugins`, οπότε λείπουν οι γραμμές που χρειάζεται στο `server/index.js`.
Πατήστε **🔧 Fix it now** σε αυτό το μήνυμα και κάντε επανεκκίνηση του FM-DX. (Το ίδιο κάνει και το βήμα εγκατάστασης.)

**Θα καταλάβουν κάτι οι ακροατές μου;**
Όχι. Ο κανονικός συντονισμός (κουμπιά, presets, πληκτρολόγηση συχνότητας, ροδέλα του ποντικιού,
κρατημένα βελάκια) δεν μπλοκάρεται ποτέ.

**Μπορεί να μπλοκάρει εμένα;**
Όχι. Όταν είστε συνδεδεμένοι ως διαχειριστής δεν μπλοκάρεστε ποτέ. Ούτε το οικιακό σας δίκτυο
ούτε προγράμματα στον ίδιο τον server (όπως το πρόσθετο Scanner) μπλοκάρονται ποτέ.

**Το αρχείο καταγραφής λέει «slowed down: too many changes» — τι σημαίνει;**
**Πρώτα, έχει σημασία η λειτουργία:** στη λειτουργία **Watch** (προεπιλογή) δεν επιβραδύνεται ούτε
μπλοκάρεται ποτέ τίποτα στην πραγματικότητα — η καταγραφή δείχνει μόνο τι *θα* έκανε το Scan Guard. Στη
λειτουργία **Enforce**, το «slowed down» είναι το πιο ήπιο βήμα, μια *προειδοποίηση* πριν από οποιοδήποτε
μπλοκάρισμα: ένας client που αλλάζει συχνότητα πάνω από **300 φορές μέσα σε 5 λεπτά** (περίπου μία φορά το
δευτερόλεπτο, ασταμάτητα — ρυθμό που κανένας άνθρωπος δεν πιάνει με το χέρι) βλέπει τον **συντονισμό του να
σταματά να λειτουργεί για περίπου ένα λεπτό**· παραμένει συνδεδεμένος και **δεν** αποσυνδέεται ούτε
μπλοκάρεται. Μόνο αν συνεχίσει (60 μπλοκαρισμένες εντολές μέσα σε 5 λεπτά) αποσυνδέεται και μπλοκάρεται για
μία ώρα. Ο «χρήστης» στην καταγραφή είναι ο **παραβατικός client (ένας scanner), ποτέ οι ακροατές σας** —
αυτοί δεν επηρεάζονται ποτέ.

**Σταματά τα ρομπότ AI που διαβάζουν τη σελίδα μου;**
Ναι, όσα λένε ποια είναι (ChatGPT, Claude, Perplexity, Common Crawl, ByteDance, Meta, Amazon και άλλα).
Ένα ρομπότ που προσποιείται ότι είναι κανονικός browser δεν αναγνωρίζεται από το όνομά του·
αν όμως σαρώσει τον δέκτη σας, το πιάνει η προστασία από τη σάρωση της μπάντας.

**Μπορώ να δω ότι τα ρομπότ AI μπλοκάρονται;**
Ναι. Ανοίξτε το `https://your-fmdx-page.example/robots.txt` στον browser: θα δείτε τη λίστα με τα
ρομπότ AI που καλούνται να μείνουν μακριά. Το παράθυρο της ασπίδας δείχνει πόσα απορρίφθηκαν.

**Είναι δωρεάν;**
Ναι, με την άδεια MIT (δείτε παρακάτω).

## Για προχωρημένους

### Πώς αποφασίζει

| Συμπεριφορά | Τι κάνει το Scan Guard σε Enforce |
|---|---|
| **Σάρωση μπάντας**: 50+ αλλαγές συχνότητας στη σειρά προς μία κατεύθυνση με το ίδιο βήμα (≤ 0.5 MHz), σε εύρος 5+ MHz, κάθε συχνότητα για 0.4 δευτ. ή περισσότερο, με σταθερό «μηχανικό» ρυθμό | αποσύνδεση + μπλοκάρισμα 60 λεπτών |
| **Μονόδρομη πορεία**: 40+ αλλαγές πάντα προς τα πάνω (ή κάτω) σε εύρος 5+ MHz με σταθερό «μηχανικό» ρυθμό (π.χ. μια λίστα γνωστών σταθμών) | αποσύνδεση + μπλοκάρισμα 60 λεπτών |
| **Πάρα πολλές αλλαγές**: πάνω από 300 αλλαγές συχνότητας σε 5 λεπτά | οι επόμενες αλλαγές αγνοούνται για ένα λεπτό· ο επισκέπτης μένει συνδεδεμένος |
| **Συνεχίζει ενώ έχει «φρενάρει»**: 60 αγνοημένες αλλαγές μέσα σε 5 λεπτά | αποσύνδεση + μπλοκάρισμα 60 λεπτών |

- **Εξαιρούνται:** οι διαχειριστές, οι επισκέπτες από το τοπικό δίκτυο και οι διευθύνσεις του whitelist.
- **Δεν μετράνε:** επαναλαμβανόμενες αλλαγές στην ίδια συχνότητα (κρατημένο πλήκτρο, reset του RDS).
- **Ποια διεύθυνση χρησιμοποιείται:** η **τελευταία** του `X-Forwarded-For`, αυτή που προσθέτει ο δικός σας reverse proxy, ώστε μια ψεύτικη κεφαλίδα να μη γλιτώνει το μπλοκάρισμα.
- **Πού κρατιούνται τα μπλοκαρίσματα:** στη μνήμη. Μια επανεκκίνηση τα καθαρίζει.

### Ρυθμίσεις (`plugins_configs/scanguard.json`, διαβάζονται ξανά αυτόματα όταν αλλάξουν)

| Ρύθμιση | Προεπιλογή | Τι σημαίνει |
|---|---|---|
| `mode` | `watch` | `watch` = μόνο καταγραφή, `enforce` = φρενάρισμα / αποσύνδεση / μπλοκάρισμα |
| `maxTunesPer5Minutes` | 300 | πόσες αλλαγές συχνότητας επιτρέπονται σε 5 λεπτά |
| `sweepMinSteps` | 50 | πόσα ίσα βήματα στη σειρά μετράνε ως σάρωση |
| `sweepMinSpanMHz` | 5.0 | ελάχιστο εύρος μιας σάρωσης |
| `sweepMaxStepMHz` | 0.5 | μεγαλύτερα άλματα δεν μετράνε ως βήματα σάρωσης |
| `monotonicMinSteps` | 40 | πόσες αλλαγές προς μία κατεύθυνση μετράνε ως «πορεία» |
| `monotonicMinSpanMHz` | 5.0 | ελάχιστο εύρος μιας «πορείας» |
| `sweepMinSecondsPerTune` | 0.4 | πιο γρήγορα = άνθρωπος που κρατά πατημένο πλήκτρο |
| `maxRhythmVariation` | 0.10 | πόσο σταθερός πρέπει να είναι ο ρυθμός για να μοιάζει αυτόματος |
| `throttledHitsToBan` | 60 | αγνοημένες αλλαγές μέσα σε 5 λεπτά πριν από μπλοκάρισμα |
| `banMinutes` | 60 | διάρκεια μπλοκαρίσματος |
| `whitelist` | `[]` | διευθύνσεις που δεν αγγίζονται ποτέ |
| `telegramLabel` | `TEF FM-DX` | όνομα στα μηνύματα Telegram |
| `aiCrawlers` | `block` | `block` = robots.txt + 403 για τα ρομπότ AI, `off` = τίποτα |
| `blockSearchEngines` | `false` | `true` = το robots.txt ζητά και από Google, Bing κ.λπ. να μη μπαίνουν |

### Μηνύματα στο Telegram (προαιρετικά)

Φτιάξτε ένα αρχείο `.scanguard-telegram` στον φάκελο του χρήστη που τρέχει το FM-DX
(δικαιώματα 600). Στέλνει το πολύ ένα μήνυμα το λεπτό.
```
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=123456789
```
